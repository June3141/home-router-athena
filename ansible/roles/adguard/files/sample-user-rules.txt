# AdGuard Home — sample custom filtering rules
# Paste these into Settings → Filters → Custom filtering rules in the
# AdGuard Home web UI as a starting point.
#
# These rules are *exclusions* (allowlist) — they bypass DNS-level
# blocking for sites whose ads come from the same domain as the actual
# content. DNS filtering cannot distinguish between the two; the right
# answer is to use a browser extension (uBlock Origin, etc.) for
# cosmetic / element-level blocking on these sites.

# YouTube — same-domain ad delivery (`*.googlevideo.com` carries both
# video chunks and ads). Blocking it breaks playback.
@@||youtube.com^
@@||youtu.be^
@@||googlevideo.com^
@@||ytimg.com^
@@||ggpht.com^
